# ADTIFY V1
**by jiyyad tools**

Web music player modern dengan UI mirip Spotify.

## Fitur
- 🔍 **Search** lagu (API musicku.web.id)
- 🎵 **Detail lagu** dengan poster besar + animasi spin saat play
- 📝 **Lirik synced** (otomatis highlight + klik untuk seek)
- ❤️ **Favorit** (disimpan di localStorage)
- 📋 **Playlist** custom
- 📱 **Responsive** mobile & desktop
- ▶️ **Player bar** tetap di bawah (bisa play di background tab)
- 🔗 Share & buka di YouTube (untuk download video)

## Cara pakai
1. Buka `index.html` di browser (atau serve dengan live server)
2. Cari lagu (contoh: `Salah Lobow`, `Coklat Stroberi`)
3. Klik lagu → halaman detail seperti screenshot WhatsApp
4. Play, lihat lirik, tambah ke favorit/playlist

## Catatan
- Streaming audio langsung dari YouTube via IFrame API
- Endpoint stream musicku saat ini butuh login YT, jadi pakai embed YouTube
- Download video: tombol download membuka YouTube + saran y2mate/savefrom

## API Source
Musicku scraper by Vamz Spectre (VamxAPI)
- search, radio/related, lyrics
